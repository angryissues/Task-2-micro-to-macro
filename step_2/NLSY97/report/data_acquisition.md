# NLSY97 — получение и подготовка входа

Получены официальные CSV, CDB, SDF, R и NLSY97 tagset из `nlsy97_all_1997-2023.zip`. Сжатый ZIP имеет размер 475462343 байта. Компоненты скачаны отдельными HTTP Range-запросами и проверены по CRC32; полный ZIP не собирался. Незавершённый первоначальный ZIP хранится отдельно с суффиксом `.partial` и не используется.

## Контроль разделения

До чтения персональных значений зафиксирован person split по SHA256('NLSY97-replication-v1:'+PUBID), первые 8 hex-цифр mod 10. Бакеты 0–5=train, 6–7=development, 8–9=confirmation. Во время извлечения проверены уникальность PUBID и соответствие длины каждой исходной строки заголовку; 8984 уникальных ID распределены по одному файлу каждый.

Разделение не использует outcomes. Подтверждающие частоты outcomes, модельные метрики и фильтры по качеству прогнозов не вычислялись. Извлечение — техническая обработка всех строк и выбранных по словарю столбцов, без отбора по значениям ответа. Защита holdout сейчас организационная: данные лежат отдельно, но не зашифрованы и доступны владельцу папки.

Файлы с выбранными столбцами сохраняют исходные значения, включая отрицательные коды, неизвестные и неоднозначные статусы. В будущем конвертере нужно применить временные ограничения и проверить доступность признаков на момент прогноза. Факт наличия недельной записи в финальном архиве ещё не доказывает, что она была известна в тот же исторический момент.
