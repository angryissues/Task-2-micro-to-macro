# Статус основной NLSY97-репликации

| Этап | Статус |
|---|---|
| Официальные исходники, CRC и словари | Получены и проверены; микроданные вне Git |
| Сохранённый первоначальный person split | Выполнено до персональной обработки |
| Calendar crosswalk, неизвестные коды и лаг признака | Выполнено; конец целевой недели определяет временной блок |
| Train/development/confirmation без пересечения людей | Выполнено; модели обучены на train |
| Полный локальный протокол до первых confirmation-метрик | Зафиксирован, конфиг и расчётный код защищены хешами |
| Последовательный доступ H1→H6 | Все шесть этапов завершены, журнал сохранён |
| H1 C0/C1/C3 с сопоставимым аудитом | Выполнено; поддержка зависит от режима |
| H2 random и 8 активных/адаптированных сравнений | Выполнено; Q2 экономит запросы против random |
| H3 MCAR/MAR/MNAR, оценённая/ошибочная response-модель | Выполнено; C1 safe, Gamma-предпосылки не подтверждены |
| H3 естественные неизвестные | Bounds/profile; истинный regret не заявляется |
| H4 P0/P1 и честный minimax point/block | Выполнено; выгоды P1 нет в этом наборе, ценовой эффект условен |
| H5 G0/G1/G2, стоимость и oracle-выполнимость | Выполнено; общего подходящего кандидата нет |
| H6 T0/T1/T2/T3/T4, три временные пары | Выполнено; прошлый победитель сохраняется, малый аудит не сертифицирует новую когорту |
| Отдельные отчёты, агрегаты и воспроизведение | Сохранены |

Не завершены и не заявляются как сделанные: все оригинальные paper-estimators/LURE и исходные эксперименты статьи CODA; отдельная месячная/недельная H4-репликация; UKHLS/PSID. Исправленный перерасчёт RLMS H4 P2 завершён отдельно, см. H4_RLMS_audit.md. Успех основного прогона означает выполнение этого зафиксированного протокола, а не положительное подтверждение каждой научной гипотезы или завершение всей публикационной программы. Сравнение авторской очереди CODA с нашим C1 уже выполнено в отдельном расширении: CODA_conditioned 76,80 против Q2 66,15 запроса при 100/100 сертификатах у обеих; см. [отчёт](../extensions/coda/report/H2_CODA_extension.md).

Confirmation-часть NLSY97 теперь использована. После неё нельзя незаметно менять группы, epsilon, модели или цены и выдавать результат за тот же независимый confirmatory test. Такие продолжения маркируются exploratory либо проверяются на новых независимо отложенных данных.
