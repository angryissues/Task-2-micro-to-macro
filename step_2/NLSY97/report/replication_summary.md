# NLSY97 — итог основной внешней проверки H1–H6

Подготовка и последовательный зафиксированный confirmation-run выполнены. Это основная внешняя репликация, а не полное повторение всех вариантов/авторских baseline-реализаций первоначального большого плана.

| Гипотеза | Итог |
|---|---|
| H1 | C1 иногда подтверждает выбор при скрытых ответах; частота существенно зависит от режима. C3 не улучшает C1 на тех же 50 ответах в основном сравнении |
| H2 | Q2: 66.15 проверки против 78.42 random, около 15.6% меньше, оба 100/100 сертификатов |
| H3 | C1 сохраняет обоснованность и при контролируемых неответах; response-aware эффект условный; Gamma-предпосылки в сильном MNAR нарушены |
| H4 | Дополнительной выгоды P1 не найдено; дешёвые блоки повышают достижимость сертификата при фиксированном бюджете, дорогие — нет |
| H5 | Для всех непустых групп нет подходящего общего кандидата даже при известных ответах; RLMS-экономия не воспроизвелась |
| H6 | Прежний HGB сохранил первое место, T1 не улучшил выбор; малой проверки новой когорты недостаточно для строгого сертификата |

Главные границы: сравнительно узкая возрастная когорта; реконструированная опубликованная разметка; маленькие группы; естественные неизвестные ответы не имеют oracle. Нельзя писать «все шесть гипотез положительно доказаны».

Полное воспроизведение оригинальных paper-estimators/LURE и исходных экспериментов статьи CODA, месячная/недельная H4-сетка как отдельная гипотеза и независимый UKHLS/PSID benchmark остаются расширениями. Исправление oracle point-gain и пересчёт RLMS-H4 P2 завершены отдельно; см. H4_RLMS_audit.md. Эти пункты не скрываются статусом выполненного основного NLSY97-run. Отдельное сравнение CODA с общим C1 выполнено: [отчёт расширения](../extensions/coda/report/H2_CODA_extension.md), 76,80 запроса у CODA_conditioned против 66,15 у Q2 при 100/100 сертификатах.
