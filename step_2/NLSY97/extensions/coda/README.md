# NLSY97: дополнительное сравнение CODA

Это расширение H2 после завершения основного H1–H6, на уже использованных данных. Основной протокол и его результаты не переписываются.

Сравниваются random, Q2, CODA_bridge (как в RLMS) и CODA_conditioned (с первоначально известными ответами в posterior). Критерий остановки для всех — точный Brier C1, epsilon=0.0025. Это адаптация авторской очереди, а не полное воспроизведение исходных экспериментов CODA.

Протокол: protocol.json. Предварительные хеши кода и версии автора: extension_lock.json. Проверки: test_extension.py. Расчёт: run.py. Генератор агрегатов и отчёта: summarize.py.

Итоговый отчёт: report/H2_CODA_extension.md. Агрегаты: results/. Исходные данные и построчные прогнозы не включаются в Git.

Авторский checkout и окружение не хранятся в репозитории проекта. Для воспроизведения использовать commit из protocol.json и команды в отчёте. Программа проверяет сохранённые хеши до расчётов; не создавать новый lock и не выдавать повторный запуск за новый независимый тест.
