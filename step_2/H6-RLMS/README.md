# H6-RLMS — надёжность выбора модели между периодами

H6 проверяет перенос выбора модели при изменении времени и состава людей. Точный сертификат старой конечной когорты не является сертификатом новой.

## Итоговое состояние

Создан отдельный временной эксперимент и выполнен полный пилот T0/T1 на трёх заранее заданных парах целевых лет: 2016→2018, 2018→2021, 2021→2024. Стек baseline/logistic/HGB обучен только один раз на исходах до 2014 года, обучающие и оценочные люди не пересекаются. Доменный классификатор использует только X, OOF-разбиение по людям. T1 маркируется plugin_transfer; будущее качество проверяется только оценщиком.

В этих сравнениях HGB остался лучшим, T0/T1 имеют нулевой regret относительно трёх кандидатов. Исправление состава улучшает баланс наблюдаемых X, но пока не улучшает выбор. Это пилотный результат, а не доказательство устойчивости при любом сдвиге.

H6 завершена в RLMS scope: T0/T1, условные T2/T3, T4 на новой конечной когорте, MAR/MNAR и контролируемые положительные/отрицательные примеры. Итоговый отчёт — `report/H6_final_report.md`, критерии завершения — `report/H6_closure_status.md`. Начальный пилот сохранён как промежуточный результат.

Основной вывод: прежний выбор оказался удачным в трёх проверенных временных парах, однако это не переносит его сертификат автоматически. Устойчивость к ограниченным изменениям весов подтверждена условно; для произвольного совместного сдвига гарантии быстро становятся неинформативными. В опыте с небольшим бюджетом новой проверки строгий сертификат может быть недоступен. Отрицательные результаты входят в отчёт.

## Воспроизведение

Исходный очищенный full_transition.csv строится скриптом H1 `build_full_h1_transition_from_sav.R` из локального SAV. Микроданные хранить вне репозитория.

```
python step_2/H6-RLMS/scripts/pilot.py --input LOCAL/full_transition.csv --config step_2/H6-RLMS/configs/temporal_v1.json --local LOCAL/h6 --out LOCAL/h6_results
python step_2/H6-RLMS/scripts/complete.py --input LOCAL/h6/h6_frozen_predictions.csv --config step_2/H6-RLMS/configs/temporal_v1.json --repo REPOSITORY_ROOT --out LOCAL/h6_completed --reps 100
python step_2/H6-RLMS/scripts/final_report.py --pilot LOCAL/h6_results --completed LOCAL/h6_completed --out LOCAL/h6_report
```

Нужны numpy, pandas, scipy, scikit-learn, tabulate, matplotlib; для подготовки SAV — R haven/dplyr. Параметры и контрольная сумма входа сохранены в results/pilot/provenance.json, версии и контрольные суммы скриптов — в results/completed/environment.json. Построчные прогнозы записываются только в --local. Здесь публикуются код, отчёты и агрегаты.
