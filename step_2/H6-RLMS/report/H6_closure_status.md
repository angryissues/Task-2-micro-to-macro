# H6 — критерии завершения RLMS-этапа

| Требование | Выполнение |
|---|---|
| Минимум три завершённых временных сравнения | 2016→2018, 2018→2021, 2021→2024 |
| Один frozen model stack и person-disjoint train/evaluation | Выполнено, train outcomes <=2014 |
| T0 и фактический будущий regret | Выполнено, HGB сохранил первое место, regret=0 |
| T1 OOF domain weights, ESS и overlap | GroupKFold по людям, clip [0.2,5], plugin_transfer |
| T2 допустимое перевзвешивание | Сетки eta 0/.25/.5/1, полные/частично скрытые старые labels |
| T2 независимая проверка вычисления | 100 LP, совпадение eta=0 с C1 и монотонность |
| T3 известный joint TV и синтетическая проверка | Выполнено; iid-переход только на синтетике |
| T3 на RLMS | Только условная чувствительность, joint rho неизвестен |
| T4 новая когорта первоначально полностью скрыта | Бюджеты 25/50/100/200, uniform+C3 и Q2+C1; Q1 дополнительный контроль |
| Фиксация active-варианта | Q2 ранее выбрана в H2 для единичной цены; без настройки на H6 |
| Статистическое покрытие при множественных проверках | Учтены пары моделей, бюджеты, когорты, сценарии и повторы |
| Единица выборки и зависимость | Одна строка на человека в год; выборка uniform без возвращения на конечной когорте |
| Неответы | MAR/MNAR, попытки оплачены, успешные ответы не объявляются случайной подвыборкой |
| Контрпример одинаковых X и смены P(y|x) | Старый победитель становится проигравшим, future regret=0.64 |
| Положительный контроль covariate shift | При известных весах regret снижается с 0.512 до 0 |
| Исходы не передаются процедуре выбора | Только old labels и раскрытые новые labels; проверена инвариантность к скрытым значениям |
| Репозиторий и воспроизводимость | Код, агрегаты, отчёт, график, конфигурация, версии и hashes; микроданные отдельно |

Завершение означает выполнение RLMS-протокола и документирование результатов, включая нулевые эффекты и отказы. Универсальное преимущество переноса, новые независимые данные и установленные истинные естественные пропуски не заявляются. Первоначальные публикационные вопросы о новизне и независимой репликации остаются отдельными от завершения вычислительного этапа.
