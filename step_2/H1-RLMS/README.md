# H1-RLMS: проверка гипотезы H1

Репозиторий объединяет реализацию C0–C3, автоматические тесты, синтетические эксперименты и сохранённые результаты пилотных экспериментов на подготовленной тестовой выборке RLMS.

## Структура
- `src/` — реализация методов и экспериментов.
- `tests/` — автоматические тесты.
- `configs/` — параметры экспериментов.
- `results/synthetic/` — результаты синтетических экспериментов.
- `results/rlms/` — сохранённые результаты real-mode, искусственного сокрытия строк и сокрытия целых людей.
- `scripts/` — скрипты подготовки входа и запуска экспериментов.
- `report/` — технический отчёт проекта и финальный отчёт PDF/LaTeX.

## Установка и тесты
Создать виртуальное окружение, установить зависимости и запустить тесты:

```bash
python -m venv .venv
source .venv/bin/activate       # macOS/Linux
python -m pip install -r requirements.txt
python -m pytest -q
```

На Windows активация окружения: `.venv\\Scripts\\activate`.

## Данные
Файлы с исходной подготовленной тестовой когортой (`h1_real_input.csv.gz`, `train.csv.gz`, `test.csv.gz`, `model_data.csv.gz`) намеренно не включены в публичный репозиторий. Перед их публикацией необходимо проверить права распространения и отсутствие чувствительной информации. Сохранённые таблицы результатов включены отдельно.

Для повторного запуска real-mode сначала подготовьте разрешённый входной файл и передайте его в соответствующую команду/скрипт. Конкретные пути и параметры запуска следует сверять с кодом скриптов.

## Результаты и ограничения
Эксперименты с пропусками используют искусственное сокрытие известных меток. Это позволяет проверить поведение методов в контролируемых сценариях, но само по себе не устанавливает механизм естественных пропусков в исходной выборке. Международные панели NLSY97, UKHLS и PSID в текущий объём не входят.
