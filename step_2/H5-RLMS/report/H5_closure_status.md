# Критерии завершения H5 на RLMS

| Требование | Статус и результат |
|---|---|
| Ранний train, будущие test outcomes, непересекающиеся люди | Выполнено: train outcomes <=2018; test outcomes 2022–2025 |
| Группы возраста, пола, высшего образования | Выполнено; образование по value labels SAV; неизвестное образование сохраняется |
| Размеры, малые группы, доли неизвестных | full_information.csv, group_visibility.csv; малые группы не исключены |
| Горизонты 1/2/3 года | Выполнено одновременно |
| Точные C1, G0/G1/G2 без oracle в решениях | Выполнено; полный перебор и проверка различных целей G1/G2 |
| Допуски 0.005 основной, 0.0025/0.01 дополнительно | Выполнено в полном аудите |
| Равномерные/удвоенные молодёжные пропуски | По 100 масок полного теста; по 50 масок active-эксперимента |
| global Q3 / равный бюджет / group bottleneck | Все три стратегии; одинаковая цена, маски и критерий остановки |
| Стоимость, распределение запросов, число неудач | active_runs.csv, active_curves.csv и paired_cost_comparison.csv |
| MAR/MNAR | Выполнено для всех трёх стратегий; неудачные попытки оплачены |
| Подходящая модель существует или её нет | Oracle-диагностика отдельно от процедур; status различает подтверждение, полную невозможность и недостаток информации |
| Контрпример глобальной гарантии без групповой | Выполнено контролируемо; сильного реального примера сверх 0.005 не обнаружено |
| Конфликтующие группы и дополнительный кандидат | Невозможность при полных ответах и восстановление выполнимости проверены |
| Воспроизводимость и безопасность данных | Скрипты, версии, контрольные суммы и агрегаты; исходники и predictions только локально |

Завершение относится к этому RLMS-протоколу. Международная репликация, новые независимые подтверждающие данные, реальная стоимость доопроса, естественные неизвестные ответы и выводы о fairness остаются за пределами доказанного результата.
