# H4-RLMS: частичные траектории

H4 проверяет, дают ли связанные годовые состояния дополнительную информацию
для строгого выбора модели. Первый MVP использует RLMS annual `j1` и горизонт
`H=3`. Endpoint, multi-horizon loss и first-exit считаются отдельными targets.

Исходные и построчные derived data остаются локальными; в Git включаются код,
тесты и агрегированные отчёты.

**Статус:** H4 закрыта в RLMS-only controlled MVP. P1 подтверждает пользу
связанной информации для first-exit; P2 показывает экономию только при низкой
заранее заданной цене блока.
