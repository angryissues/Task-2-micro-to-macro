# H4-RLMS: частичные траектории

Исправленный анализ завершён. Утечка скрытого ответа при выборе точки и ошибка P0 для накопленного выхода устранены. Прежние сравнительные числа заменены пересчётом без переобучения моделей.

На 300 уникальных test-участниках и 50 масках при цене блока 1 расходы — 77,96 против 98,72 у точек (21,0% экономии, 50/50 сертификатов). При дорогих блоках преимущества нет. Информационный выигрыш P1 оказался небольшим.

Актуальные [отчёт](report/H4_corrected_report.md), [статус](report/H4_closure_status.md), [аудит](report/H4_query_policy_audit.md). Протокол: `configs/p2_correction_v2.json`, агрегаты: `results/correction_v2/`.

H4 использует annual RLMS `j1`, H=3. Endpoint, multi-horizon и накопленный выход на будущих годовых контрольных точках — разные цели. Пропуски в проверке создаются искусственно на известных исходах.

Статус: исправление RLMS-only controlled протокола выполнено, результат условный и ценозависимый. Исходные и построчные данные остаются локальными; для Git предназначены код, тесты и агрегированные результаты.
